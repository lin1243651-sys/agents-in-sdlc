Explora GitHub Copilot a lo largo del ciclo de vida del desarrollo de software mediante escenarios realistas, una aplicación completa y un backlog compartido. Trabajarás de forma iterativa para planificar cambios, escribir código, probar el comportamiento, revisar solicitudes de incorporación de cambios y gestionar el trabajo con agentes.

## Escenario

Eres un nuevo desarrollador de Tailspin Toys, una empresa ficticia que ofrece financiación colectiva para juegos de mesa con temática de desarrollo. El backlog del equipo ya está registrado como incidencias de GitHub, listas para que las abordes. Incluye tareas de funcionalidades, como filtros y paginación, además de mejoras de calidad, como accesibilidad y estándares de programación.

## Elige tu entorno

GitHub Copilot está disponible en los entornos en los que trabajas. Elige el que mejor se adapte a tu forma de desarrollar. Cada taller empieza con su propia configuración y utiliza el escenario compartido de Tailspin Toys.

### [GitHub Copilot CLI][cli]

Usa el asistente con agentes desde el terminal. Trabaja con los modos Plan y Autopilot, instrucciones, habilidades, agentes personalizados, Playwright MCP, Agent Merge y prácticos comandos de barra.

### [Aplicación GitHub Copilot][app]

Ejecuta sesiones de agente en paralelo, cambia los modos de sesión, colabora en canvases y gestiona incidencias y solicitudes de incorporación de cambios de GitHub desde la aplicación de escritorio.

### [GitHub Copilot cloud agent][cloud]

Asigna incidencias de GitHub a un agente asíncrono, guía su trabajo, supervisa el progreso y revisa las solicitudes de incorporación de cambios que abre.

### [Visual Studio Code][vscode]

Usa GitHub Copilot en Visual Studio Code y GitHub Codespaces. Trabaja con el modo agente de Copilot Chat, servidores MCP y agentes personalizados sin salir del editor.
